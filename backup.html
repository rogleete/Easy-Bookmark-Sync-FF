Manual Backups

These are separate, permanent snapshots you create yourself - they live in their own folder in Drive and are never touched by the regular automatic sync. Good for having a fixed point to fall back to if something ever goes sideways with the live sync.

Restore a backup

Restoring replaces every bookmark currently in this browser with what's in the selected backup. This can't be undone.

Restoring a backup is only available on the Master Sync Source browser. This computer is set to Destination Sync, so it only ever pulls bookmarks down from the live sync file.
