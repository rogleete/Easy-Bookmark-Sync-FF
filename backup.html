Manual Backups

These are separate, permanent snapshots you create yourself - they live in their own folder in Drive and are never touched by the regular automatic sync. Good for having a fixed point to fall back to if something ever goes sideways with the live sync.

Oldest backups are deleted automatically once this limit is passed. The "Initial Backup" created automatically on first sign-in counts toward this limit too.

Restore a backup

Restoring replaces every bookmark currently in this browser with what's in the selected backup. This can't be undone.

Restoring a backup is only available on Master Sync Source or Merge (Two-Way). This computer is set to Destination Sync, so it only ever pulls bookmarks down from whatever the group already has.

This device is set to Merge (Two-Way). Restoring will make it re-join the shared group from scratch on its next sync - same as a brand new device joining for the first time, including a fresh Pre-Merge Backup and reconciliation pass.
