Easy Bookmark Sync - Setup

This extension talks straight to your own Google Drive, so it needs a Google Cloud OAuth Client ID before it can sign in. It's a one-time, five minute setup.

  1. Open the Google Cloud Console credentials page for your project (or create a new project first if you don't have one yet).
    Open Google Cloud Console → Credentials
  2. Create an OAuth client of type Web application, and add the redirect URI below to its "Authorized redirect URIs" list. If you use this extension in more than one browser (Chrome and Edge, for example), come back to this page in each browser and add each one's URI to the same OAuth client - one Client ID can hold several redirect URIs.
  3. Copy the Client ID Google gives you (it ends in .apps.googleusercontent.com) and paste it below.
